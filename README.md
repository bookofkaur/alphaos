# AlphaOS MVP

AlphaOS is a browser-based options research and paper-trading decision-support tool.

## Live site

After GitHub Pages is enabled from the `main` branch root, the app will be available at:

`https://bookofkaur.github.io/alphaos/`

## What works

- Transparent setup scoring
- Calls/puts strategy suggestions
- Risk-based contract sizing
- Watchlist
- Paper trade journal
- Journal JSON export/import
- Options learning center

## Current limitations

- No live quotes or option chains
- No brokerage execution or Fidelity authentication
- No statistically validated predictive model

Options can expire worthless. This prototype is educational decision support, not personalized financial advice.
